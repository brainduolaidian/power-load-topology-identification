# Power Load Identification & Topology Identification

Non-intrusive load monitoring (NILM) and low-voltage topology identification algorithms based on **public datasets** (EV-CPW + synthetic data).

## Project Overview

This project implements two independent power system analysis modules:

1. **Load Identification**: Identifies EV charging events from household current/voltage waveforms and classifies chargers (EV vs laptop) using harmonic domain features.
2. **Topology Identification**: Recovers the tree-shaped power supply topology from smart meter time-series data using voltage correlation and current conservation, without ground-truth labels.

## Data Sources

All data used in this project comes from public datasets or synthetic generation — no proprietary or private data is included.

| Module | Dataset | Source | Description |

## Module 1: Load Identification

### Algorithm Pipeline

| Step | Method | Key Result |
|------|--------|------------|
| Cycle counting | Positive-slope zero-crossing detection + glitch filter | Accurate cycle counts for 30kHz/60Hz waveforms |
| Harmonic feature extraction | Per-cycle FFT, 2nd-9th harmonics (amplitude CV, phase std) | Rich feature set per waveform |
| Charger classification | Two-stage rule classifier (RMS → harmonic CV → inrush ratio) | **89.7%** (subset) / **95.6%** (full EV-CPW) |

### Classifier Design

The rule-based classifier uses three sequential criteria calibrated on public data:

1. **Primary: RMS steady current** — EV chargers draw >5A steady (Level 2 charging), laptop chargers <1A
2. **Secondary: 5th harmonic amplitude CV** — Laptop chargers show >0.30 (no PFC, load variation), EV <0.20
3. **Tertiary: Inrush ratio** — Laptop chargers >3.5× (soft-start), EV <2.5× (PFC softens inrush)

### Results

**With included sample data** (9 EV-CPW samples + 20 laptop samples):

## Module 2: Topology Identification

### Algorithm Pipeline

| Step | Method | Key Result |
|------|--------|------------|
| Time alignment | Cross-correlation shift search | All meters aligned to reference |
| Voltage initial assignment | Per-phase Pearson correlation between user and rail voltages | 97.4% accuracy (189/194) |
| Current conservation refinement | Gated iterative reassignment for low-margin users | Converged, no regression |
| Confidence grading | HIGH / MED / LOW based on voltage margin and score | Honest quality reporting |

### Key Design Decisions

- **Voltage method first**: Same-feeder meters share voltage fluctuations → high correlation; cross-feeder → low. This gives reliable but coarse initial assignment.
- **Gated refinement**: Only move users with low voltage margin AND poor current fit. Gate threshold (corr > 0.25) prevents random jumps. Anti-jitter: skip if already well-fit.
- **Confidence grading**: Users with high voltage margin → HIGH confidence. Low margin + decent score → MED. Low margin + low score → LOW.

## Quick Start

```bash
# Install dependencies
pip install -r requirements.txt

# --- Module 1: Load Identification ---
# Step 1: Generate synthetic laptop charger waveforms
python load_identification/code/generate_laptop_charger.py

# Step 2: Run load identification (uses EV-CPW samples + laptop samples)
python load_identification/code/load_identification.py

# --- Module 2: Topology Identification ---
# Step 1: Generate synthetic LV network data
python topology_identification/code/generate_lv_network.py

# Step 2: Run topology identification
python topology_identification/code/topology_identification.py
```

> **Note**: For the full EV-CPW dataset (72 waveforms), see `load_identification/data/ev_cpw_samples/DOWNLOAD_INSTRUCTIONS.md`.
